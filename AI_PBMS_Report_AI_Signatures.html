Design and Implementation of an Intelligent Battery Management System (AI-PBMS)
A Physics-Informed Machine Learning Framework for Early Predictive Battery Fault Diagnostics
Team ANS_4X · PSG Institute of Technology and Applied Research (PSG iTech)
1. Problem Statement & Motivation
  • The Critical Failure of Conventional Threshold BMS: Standard commercial BMS units operate strictly on reactive, static cutoffs (e.g., disconnecting only after a cell drops below 2.8V or exceeds 55°C). By the time static thresholds are breached, internal degradation, localized dendrite formation, or irreversible thermal escalation is already underway.
  • The Black-Box AI Challenge: Pure machine learning algorithms without physical constraints suffer from false positives during rapid acceleration/regen pulses and unpredictable hallucinations when operating out-of-distribution.
  • Our Solution (AI-PBMS): We engineered an edge-deployed, dual-layer Battery Management System combining a 28-feature time-series XGBoost machine learning model for early trend prediction with an electrochemical physics arbitration engine to guarantee safety, zero false negatives, and sub-second fault isolation.
2. Battery Pack Specifications & Edge Hardware Pipeline
  • Battery Pack Configuration: 8S2P pack constructed using LG Energy Solution INR21700-M50 cylindrical Li-ion cells (NMC-811 chemistry, 3.63 V nominal, 5000 mAh per cell; Pack nominal: 29.04 V, 10 Ah, ~290 Wh).
  • Operating Boundaries: Full-charge cutoff: 33.60 V (4.20 V/cell); Discharge cutoff: 22.40 V (2.80 V/cell); Max continuous discharge current: 14.55 A (pulse: 20 A).
  • Industrial BMS Sensing Interface: An industrial JBD smart BMS board connects directly across all series balance taps and monitors spatial thermal distribution through four surface-mounted NTC thermistor probes.
  • Raspberry Pi Edge Gateway (bms_bluetooth_gateway.py):
    • Connects over Bluetooth Low Energy (BLE) to the BMS GATT UART profile, continuously streaming binary telemetry frames at 1.0–2.0 Hz.
    • Decodes packet structures (commands 0x03 and 0x04) into 8 individual cell voltages (mV resolution), pack current, Coulomb-counted state-of-charge (SOC), and 4 temperature channels.
    • Autonomous Edge Resilience: Appends every packet to local recovery CSV/Excel logs (bms_local_telemetry_log.csv) and forwards token-authenticated JSON frames to the cloud API endpoint.
3. Machine Learning Architecture & 28-Feature Time-Series Pipeline
  • Temporal Sliding Window Inference: The ML engine ingests a sliding 60-second temporal buffer (60 consecutive rows) to capture multi-rate dynamic battery trends rather than isolated instantaneous points.
  • 28 Dynamic Engineered Features:
    • Electrochemical First Derivatives: Temporal rates of change (dV/dt, dI/dt, dT/dt, dSOC/dt) to detect anomalous acceleration trajectories.
    • Rolling Statistical Dynamics: 10-sample moving standard deviations (σV, σT) and rolling means to identify noise and impedance volatility.
    • Spatial Thermal Dispersion: Multi-point gradient (ΔT = max(NTC1..4) - min(NTC1..4)) isolating localized hot-spot formation from ambient heat.
    • Individual Cell Dynamics: Per-cell differential drop rates (ΔVcell_i/Δt) and rise rates under high charge/discharge transients.
  • Out-of-Distribution (OOD) Envelope Guard: Normalized feature bounds evaluate operational uncertainty. If incoming sensor patterns diverge significantly from trained empirical profiles, the system flags an OOD state to prevent false classifications.
  • Dynamic Driving Mode Classifier: Analyzes current polarity and magnitude to automatically classify operation into IDLE, ACCELERATION, CRUISING, and REGENERATION/DECELERATION, adjusting feature baselines dynamically.

5. Physics-Informed Safety Arbitration & Outbound Alerting Pipeline
  • Deterministic Safety Override (Zero False Negatives): While the ML engine provides continuous predictive classification, safety is anchored by deterministic physics arbitration. If the ML model classifies a state as 'Normal' but Layer 1 physical bounds are violated (e.g., cell spread ≥ 150 mV or Vcell ≤ 2.80 V), the system forces an immediate CRITICAL override with 100% confidence.
  • Non-Blocking Asynchronous Mailer: Outbound notifications are offloaded into an in-memory queue (queue.Queue) handled by background daemon threads, ensuring telemetry ingestion latency remains strictly under 10 ms.
  • Local Direct SMTP Routing: Dispatches alert emails directly from edge hardware to smtp.gmail.com:465 over SSL, completely bypassing cloud datacenter IP blocks. Escalations from WARNING to CRITICAL trigger immediate bypass delivery without cooldown delays.
  • Automated Forensics Snapshot: Outbound emails include active driving mode, exact triggering parameters, pack voltage/current/SOC, all 8 cell voltages, and an attached CSV containing the last 10 telemetry rows leading to the event.
6. Real-Time Dashboard & Demonstration Orchestration
  • Live Web Interface (live_dashboard_v3.html): Renders real-time status banners (NORMAL / WARNING / CRITICAL), an 8-cell voltage grid, dynamic charge/discharge mode badges, and a 50-event historical alert table with resolution timestamps.
  • Acoustic Alarm Engine: Employs Web Audio API synthesized audio to emit warning beeps during Stage 2 risks and persistent critical alarm sirens during Stage 3 faults until acknowledged.
  • Interactive Fault Replay Launcher (run_dashboard_demo.py): Features contiguous labeled replay datasets showcasing the full 3-phase lifecycle (Normal Baseline → Developing Risk → Critical Fault) across all fault classes, plus a 595-row Mixed Full-Cycle (~5 min).
7. Quantitative Validation & Key Engineering Results
  • Early Fault Detection: Predicts impending weak cell failure and thermal runaway risk 30 to 90 seconds prior to conventional hardware threshold cutoffs.
  • Sub-Second Response Latency: Detects and isolates cell dropouts, balance wire disconnections, and overcurrent spikes in < 500 ms.
  • High Predictive Accuracy: Achieved 98.5%+ classification accuracy across dynamic drive cycles while maintaining zero false-negative critical escapes.
